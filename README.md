# Heuristic — Startup Job Board (IT)

Вебзастосунок для пошуку роботи в IT-стартапах, розроблений у межах лабораторних робіт із курсу «Веб-технології та веб-дизайн». Проєкт реалізує адаптивний інтерфейс за методологією **БЕМ** та архітектурою **SCSS 7-1**.

**Preview:** https://set-typhon.github.io/web-job-board/

---

## Основний функціонал та сторінки

Інтерфейс застосунку побудований англійською мовою та охоплює 4 ключові сторінки:

1. **Home (`/`):**
   * Hero-секція з адаптивним фоновим зображенням та презентацією платформи.
   * Форма швидкого пошуку вакансій за ключовими словами, локацією, форматом роботи та типом зайнятості.
   * Каталог популярних напрямів (SaaS, AI, Enterprise Software, E-commerce, Fintech, Manufacturing).
   * Список рекомендованих вакансій, блок для зв'язку з інвесторами та переваги сервісу.
2. **Jobs (`/jobs`):**
   * Повний каталог вакансій із пошуком, сортуванням (`Most popular`, `Newest`, `Company name`) та пагінацією.
   * Адаптивна система фільтрації: бічна панель на десктопі та компактне випадаюче меню на мобільних пристроях і планшетах.
3. **Job Details (`/jobs/:id`):**
   * Детальний опис позиції, вимоги, обов'язки та таблиця ключових умов роботи.
   * Картка компанії з основними фактами та тегами.
   * Фіксована нижня панель швидких дій (`Apply for this job` та `Save`) для зручної взаємодії на мобільних екранах.
4. **Apply (`/apply/:id`):**
   * Форма відгуку на обрану вакансію з полями для контактних даних, резюме та супровідного листа.

## Архітектура стилів (SCSS 7-1)

Вихідні стилі організовані за стандартом **7-1** та компілюються у `css/main.css`:

```text
src/scss/
├── abstracts/
│   ├── _variables.scss    # Кольори, шрифти, радіуси, брейкпоінти та шкала відступів
│   ├── _functions.scss    # Конвертер px у rem()
│   └── _mixins.scss       # Міксини для Flexbox, Grid, контейнерів, типографіки та кастомної сітки
├── base/
│   ├── _reset.scss        # Скидання стандартних стилів браузера
│   ├── _base.scss         # Базові стилі сторінки, посилань, списків та зображень
│   ├── _typography.scss   # Адаптивна типографіка заголовків (Poppins / Inter)
│   └── _utilities.scss    # Utility-класи (spacing, visibility), @keyframes анімації та @media print
├── components/
│   ├── _buttons.scss      # Плейсхолдери та модифікатори кнопок, перемикач мови
│   ├── _cards.scss        # Стилі карток вакансій, категорій, компаній та переваг
│   ├── _forms.scss        # Поля вводу, кастомні селекти з іконками та форми заявок
│   └── _navigation.scss   # Хлібні крихти та пагінація
├── layout/
│   ├── _grid.scss         # Кастомна 12-колонкова сітка (.l-container, .l-row, .l-col-*) з gutters
│   ├── _header.scss       # Липкий хедер та адаптивне випадаюче меню
│   └── _footer.scss       # Багаторівневий футер із адаптивною сіткою контактів та соцмереж
├── pages/
│   ├── _home.scss         # Стилі головної сторінки
│   ├── _jobs.scss         # Стилі каталогу вакансій та випадаючих фільтрів
│   ├── _job-details.scss  # Стилі сторінки вакансії та фіксованої панелі дій
│   └── _apply.scss        # Стилі сторінки подачі заявки
├── themes/
│   └── _default.scss      # CSS-змінні світлої теми (:root)
├── vendors/
│   └── _normalize.scss    # Базова нормалізація елементів
└── main.scss              # Головна точка входу, що об'єднує всі модулі
